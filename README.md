<h2>📌 Overview</h2>

<p>
This project focuses on Exploratory Data Analysis (EDA) using SQL on the Superstore dataset.
The goal is to extract business insights related to sales, customers, shipping, and profitability.
</p>

<hr>

<h2>🛠️ Tools Used</h2>

<ul>
  <li>🗄️ SQL Server</li>
  <li>📜 SQL Queries (T-SQL)</li>
  <li>📁 Data stored in CSV format</li>
  <li>📊 Data Analysis (EDA techniques)</li>
</ul>

<hr>

<h2>📂 Dataset</h2>

<p>The dataset contains sales transactions including:</p>

<ul>
  <li>🛒 Orders</li>
  <li>👥 Customers</li>
  <li>💰 Sales</li>
  <li>📈 Profit</li>
  <li>🚚 Shipping details</li>
  <li>🌍 Regions and Cities</li>
</ul>

<hr>

<h2>📊 Key Analysis Performed</h2>

<h3>1️⃣ Sales by City</h3>

<ul>
  <li>✅ Identified top-performing cities based on total sales</li>
  <li>✅ Calculated percentage contribution of each city to overall sales</li>
</ul>

<hr>

<h3>2️⃣ Customer Transactions Analysis</h3>

<ul>
  <li>✅ Measured number of transactions per customer</li>
  <li>✅ Identified most active customers</li>
</ul>

<hr>

<h3>3️⃣ Sales by Segment</h3>

<ul>
  <li>✅ Compared sales performance across Consumer, Corporate, and Home Office segments</li>
</ul>

<hr>

<h3>4️⃣ Customer Segmentation</h3>

<p>Created customer levels using SQL CASE statement:</p>

<ul>
  <li>⭐ VIP Customers</li>
  <li>📌 Average Customers</li>
  <li>👤 Normal Customers</li>
</ul>

<hr>

<h3>5️⃣ Shipping Analysis</h3>

<ul>
  <li>✅ Calculated shipping duration using DATEDIFF</li>
  <li>✅ Analyzed average shipping days per region</li>
</ul>

<hr>

<h3>6️⃣ Sales Over Time</h3>

<ul>
  <li>✅ Analyzed yearly sales trends</li>
  <li>✅ Identified growth patterns across years</li>
</ul>

<hr>

<h3>7️⃣ Top Customers by Sales</h3>

<ul>
  <li>✅ Identified top 10 customers contributing highest revenue</li>
</ul>

<hr>

<h3>8️⃣ Category Performance</h3>

<p>Compared Sales vs Profit across product categories:</p>

<ul>
  <li>💻 Technology</li>
  <li>🪑 Furniture</li>
  <li>📦 Office Supplies</li>
</ul>

<hr>

<h3>9️⃣ High Sales but Low Profit Cities</h3>

<ul>
  <li>✅ Identified cities with high revenue but low profitability</li>
</ul>

<hr>

<h2>📈 Key Insights</h2>

<ul>
  <li>📊 Sales increased significantly over time, showing positive growth trend</li>
  <li>📉 Certain cities generate high sales but low profit due to operational costs</li>
  <li>💻 Technology category generates highest revenue</li>
  <li>🚚 Shipping delays vary across regions</li>
  <li>👥 A small group of customers contributes significantly to total sales</li>
</ul>
